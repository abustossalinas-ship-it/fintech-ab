# Ariel Bustos Salinas Portfolio

Sitio web estático para presentar el perfil profesional, experiencia, competencias, formación y certificaciones de Ariel Bustos Salinas.

## Publicación

El sitio no requiere build ni dependencias. Puede publicarse directamente con GitHub Pages usando la raíz del repositorio como fuente.

## Archivos principales

- `index.html`: contenido y estructura de la landing.
- `styles.css`: estilos responsive y diseño visual.
- `script.js`: navegación móvil, año dinámico y animaciones de entrada.
